# Q120 - Student Management System

## 📌 Overview

This mini project was developed as the final assignment (**Q120**) of the **25CSE235 C Programming Summer Assignment**. It demonstrates the use of arrays, strings, functions, and menu-driven programming to manage student records.

## ✨ Features

- Add Student Record
- Display All Students
- Search Student by Roll Number
- Update Student Marks
- Delete Student Record
- Exit Program

## 🛠️ Concepts Used

- Arrays
- Strings
- Functions
- Loops
- Conditional Statements
- Switch Case
- Menu-Driven Programming

## 📂 Files

| File | Description |
|------|-------------|
| `q120.c` | Student Management System source code |

## ▶️ Compilation & Execution

```bash
gcc q120.c -o q120
./q120
```

## 📋 Sample Menu

```text
===== STUDENT MANAGEMENT SYSTEM =====
1. Add Student
2. Display Students
3. Search Student
4. Update Marks
5. Delete Student
6. Exit
```

## 🎯 Learning Outcome

This project combines the major concepts learned throughout the 30-day C programming assignment into a single menu-driven application.
